Mes ressources

Aura personnalisée

Remplace l'aura de ton skin. Visible par tous les joueurs.

Expulser : le joueur est déconnecté (il peut revenir en rechargeant). Bannir : son adresse IP ne peut plus se connecter du tout.

Clic sur un objet : il arrive dans ton sac à dos.

Le monstre apparaît à côté de toi (Plaines Sauvages, donjons, tutoriel). Si tu n'es pas l'hôte ★, tu le deviens pour le faire apparaître.

Surveillance permanente (mise à jour toutes les 5 s) : sauvegardes refusées, monstres refusés, dégâts au-delà de l'équipement, coups de trop loin, longues séries sans perdre de vie près d'un boss, déplacements impossibles. Rouge : à vérifier en priorité. Les compteurs repartent de zéro au redémarrage du serveur.

Sauvegardes refusées par le serveur (objets modifiés, monnaies injustifiées, progression trop rapide). Le joueur a été remis à sa dernière sauvegarde valide. Quelques refus isolés peuvent être des faux positifs ; beaucoup de refus pour le même compte = triche probable.

Applique un état pour tester. « Joueurs à l'écran » = les joueurs visibles autour de toi, dans la même zone.

Vue 1re personne (test)

Pour un autre joueur : onglet Joueurs, boutons « 1re pers. ». En 1re personne : clic dans le jeu pour capturer la souris (elle fait tourner la vue), Z/S avancer/reculer, Q/D pas de côté, clic gauche pour tirer, Échap pour libérer la souris.

Joueurs connectés qui ont activé le mode admin (mot de passe vérifié par le serveur). Si tu vois un inconnu ici, change le mot de passe.

Ces mots sont remplacés par des étoiles dans le chat et les pseudos. Le serveur applique le même filtre. Les variantes (majuscules, accents, lettres répétées, 0 pour o, 4 pour a…) sont reconnues.

Tape /god off dans le chat pour quitter le mode admin
